- (decision) Inventaire équipement (FR-6/7/8/9) reste un champ JSON enrichi dans Character.sheetData.equipment, pas de migration relationnelle. Rationale : spécifique Ryuutama (varie par système), toujours chargé/sauvegardé comme un bloc entier, aucun besoin de requête cross-personnage identifié. Cohérent avec le pattern déjà appliqué à 100% du reste de sheetData/ContentEntry.data dans ce projet. Réversible plus tard si besoin réel émerge (migration = script de transformation, pas un enfermement).
- (decision) Invalidation des sessions actives au reset de mot de passe (FR-11) : nouvelle table d'index inverse userId -> sid, tenue à jour au login/logout. Choix utilisateur (plus robuste/explicite que le versioning par timestamp ou la requête JSON sur Session.sess).
- (decision) FR-22 (idempotence) recentré sur la garde UI (FR-1) uniquement — pas de mécanisme de clé d'idempotence côté serveur. Risque résiduel de vrai retry réseau accepté, cohérent avec les autres risques déjà acceptés dans ce projet.
- (decision) FR-15 (détection PDF renforcée) : réutilise pdf-lib (déjà dépendance du projet) via PDFDocument.load() en validation structurelle, pas de nouvelle librairie de détection de fichier.
- (decision) [ADOPTED] Hachage token reset = argon2 (réutilise le pattern User.passwordHash). Purge tokens expirés = @Cron (réutilise NotificationsService). Pagination FR-18 = offset/limit Prisma skip/take, pas de curseur. Anti-double-clic Epic 1 = signal pending local par composant (pattern déjà 3x dans le projet), pas de nouvelle abstraction partagée. EXIF = nouvelle dépendance sharp appliquée à l'upload portrait.
- (decision) Nouveau modèle Prisma UserSession (id, userId FK->User cascade, sid FK->Session.sid, createdAt) pour l'index inverse de sessions. Ligne créée au login, supprimée au logout ; au reset mdp, suppression des lignes UserSession de l'utilisateur ET des lignes Session correspondantes (jointure sur sid) pour rester synchronisé. Vit dans AuthModule existant. Aucun nouveau module NestJS pour ce palier - uniquement modifications de modules existants (AuthModule, CharacterModule, ScenariosModule).
- (event) Coaching terminé, toutes les décisions actées. Passage à la distillation de la spine.
