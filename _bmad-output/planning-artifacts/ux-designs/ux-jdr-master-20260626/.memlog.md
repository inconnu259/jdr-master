# UX Memlog — Palier 2 Calendrier

- event: UX initié, intent = Create, source = prd-jdr-master-20260626/prd.md
- assumption: Stack visuelle existante = Angular Material 22 + thème custom JDR
- decision: Nom produit = "jdr-master" temporaire, logo = à définir plus tard
- decision: Ton = léger et humoristique dans les microcopy
- decision: Dark mode / dark-leaning
- assumption: Pas de textures, pas d'images, pas d'icônes complexes — typographie + couleurs + formes
- decision: Utilisateur aime le vert comme accent — à explorer avec autres couleurs
- idea: Calendrier mini = 4 zones cliquables par jour : rectangle avec haut=matin, milieu=AM, bas=soir, bande droite 1/5 = journée entière
- idea: Alternative calendrier = click sur jour → popup sélection slot + durée (multi-jour à la Google Maps)
- decision: Interaction calendrier = depuis le calendrier lui-même (cliquer un jour → popup contrainte). Pas de bouton "+ Ajouter" séparé.
- decision: Vue mois : indicateur par slot (3 petits traits matin/AM/soir en bas de chaque case) au lieu d'une seule couleur — permet de voir "dispo le soir seulement" sans ambiguïté. Couleur jaune/ambre = "mixte" non retenu au profit des 3 segments.
- decision: Desktop MJ = layout split 60/40 (calendrier gauche / panneau résultats droit sticky) ✅ validé
- decision: Vue mois = 3 segments colorés en bas de chaque case (matin|AM|soir) ✅ validé, lisibles à cette taille
- decision: Popup desktop = panel latéral droit 320px (pas modale centrée, pas bottom-sheet) ✅ validé
- decision: Popup mobile = bottom-sheet
- event: Discovery complète — toutes les décisions UX validées, passage en Finalize
- decision: Tonalité = 3 personnalités distinctes couplées au thème : Grimoire Émeraude (magie/bibliothèque), Forêt Ancienne (nature/elfes), Médiéval Steampunk (engrenages/vapeur). ThemeToneService Angular, ~25-30 clés.
- event: spines finalisés — DESIGN.md + EXPERIENCE.md écrits, status: final
- decision: Calendrier = vue principale pour déclarer les contraintes. Vues semaine + mois au minimum.
- decision: Deux thèmes utilisateur : Grimoire Émeraude + Forêt Ancienne — l'utilisateur peut switcher dans ses préférences.
- decision: 3 thèmes retenus : Grimoire Émeraude + Forêt Ancienne + Médiéval Steampunk (utilisateur switche dans ses préférences)
- decision: Direction 3 = medieval/steampunk (pas terminal/hacker — trop "Fallout geek", pas assez lisible)
- decision: Grimoire Émeraude (violet+vert sauge) et Forêt Ancienne (vert émeraude+or) sont les deux finalistes retenus comme thèmes
